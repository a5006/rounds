# ROUND PRO

根据 `round_pro_boxing_timer_tactical_combat_chrono.html` 实现的 React 18 + Vite + Tailwind 移动训练应用。

## 运行

```sh
npm install
npm run dev
```

默认打开 http://localhost:5173 。手机和电脑连接同一 Wi-Fi，使用终端显示的 Network 地址访问。

```sh
npm test
npm run build
npm run preview
```

`dist/` 为可部署产物。生产服务器需要把 React 路由请求回退到 `/index.html`；所有资源以站点根路径部署。

## 页面与功能

- 首页：训练配置、拳击 / HIIT / 敏捷三种预设、自定义方案入口。
- 参数编辑：点击数值卡片打开底部滚轮，分钟 / 秒双列选择（5 秒步长）、1–30 回合单列选择，带快捷预设；取消保留原值，确定更新预计总时长。训练最少 5 秒，准备和休息支持 0 秒，单阶段可设至 10:55。
- 准备阶段每秒播放一次短促电子表滴声（2400Hz）；最后 3、2、1 秒保持普通滴声，在 0 秒进入训练时升高到 3200Hz 并略微延长，形成“滴、滴、滴、滴！”的结束提示。暂停 / 静音停止；准备正常结束时高音滴声代替开场铃。
- 休息阶段只在剩余 3、2、1 秒时各滴一次，最后 1 秒同样提高音调。暂停或静音停止；延长休息后重新进入最后 3 秒会重新提示。
- 准备 → 训练 → 休息 → 战报：真实多回合状态机，支持 0 秒准备 / 0 秒休息 / 最后回合跳过休息。
- 暂停：保留阶段、回合及毫秒余量；继续、重置阶段、确认结束。
- 训练延时与休息延时；进度环按剩余毫秒平滑变化。
- 秒表：`performance.now()` + `requestAnimationFrame`，分圈、最快圈、平均圈速、CSV 导出。
- 战报：真实训练 / 休息 / 总时长和回合图表；系统分享、剪贴板或文件导出。
- 配置、偏好、训练状态、最近战报和分圈历史保存在设备本地。
- 独立设置页、合成训练铃声、中文阶段播报、支持设备上的振动与屏幕常亮。
- 训练最后 3、2、1 秒中文播报“三、二、一”，遵循中文语音开关和静音。
- 每个训练回合按音频时钟提前安排剩余 10 秒的三下木板敲击预警。可在方案 / 设置中关闭，遵循全局静音；暂停、休息和准备阶段不播放。设置页可单独试听。
- 敲板声使用 ashboy34 的两块木板互拍实录（boardclapdry.wav，CC BY 3.0，详见 assets/audio/CREDITS.md），支持离线；同一回合延时或暂停恢复不会重复预警，重置本回合后可再次预警。

## 动效

原稿的 pulse、ping、环境光晕、触击缩放和开关滑动均保留。

| 动效 | 实现 |
| --- | --- |
| 计时环连续缩短 | 每 50ms 校准余量，SVG `stroke-dashoffset` + 60ms 线性过渡 |
| 数字更新 | 单个变化数字的 240ms 位移 / 淡入 / 模糊消退 |
| 页面切换 | 340ms 淡入，避免变换祖先影响固定导航 |
| 卡片进入 | 480ms 上移淡入，45 / 80ms 错峰 |
| 准备 / 战斗 / 休息表盘 | 420–650ms 缩放进入 |
| 结束确认条 | 220ms 缩放与淡入 |
| 战报徽章 | 700ms 弹性缩放及旋转 |
| 回合柱状图 | 自底部展开，35ms 错峰 |
| 分圈记录 | 280ms 插入动效 |
| 无障碍 | 遵循 `prefers-reduced-motion` |

## iOS / Android

这是移动 Web/PWA 应用，可在 iOS Safari、Android Chrome 中运行；没有生成 IPA / APK 原生安装包。

- 支持 `viewport-fit=cover`、顶部 / 底部安全区和动态视口高度。
- 320px 起的窄屏布局、横屏滚动、触摸反馈，保留浏览器缩放。
- iOS 通过分享菜单「添加到主屏幕」，Android 通过浏览器安装 / 添加到主屏幕。
- 生产构建生成离线 Service Worker，预缓存应用页面、脚本、字体、图片和图标。开发模式不注册。
- PWA 离线、系统分享、Wake Lock 需要 HTTPS 或 localhost 安全环境。同 Wi-Fi 的 HTTP 地址用于布局及交互预览。
- iOS 首次声音需用户触击来解锁。振动按浏览器能力降级，iOS Safari 无原生振动支持。
- 浏览器可能在锁屏或后台暂停 JS / 声音；重新进入按实际经过时间校准阶段。此版本不能保证锁屏后台持续响铃。
- 不接入心率或热量传感器，相关位置显示未连接，避免把稿件示例数据当作实际测量。
- 尚未在实体 iOS / Android 设备做验收；桌面浏览器的手机视口测试不等于真机测试。

## 代码

- `src/App.jsx`：忠于参考稿的页面、组件、路由。
- `src/runtime.jsx`：训练共享状态、声音 / 振动 / Wake Lock、持久化、秒表、导出。
- `src/session.js`：与 UI 独立的训练计时状态机。
- `src/styles.css`：移动适配与动画。
- `tailwind.config.cjs`：参考稿原始色彩、间距与字号令牌。
- `vite.config.js`：构建及带版本号的离线缓存。
- `scripts/generate-icons.mjs`：从 SVG 生成主屏幕图标。

## 验证

`npm test` 检查阶段流转、暂停恢复、后台补时、0 秒准备 / 休息、最后休息、延时和跳阶段。

`npm run build` 后，`npm run test:pwa` 验证 Service Worker 缓存清单资源均存在、导航离线回退和普通资源缓存。
