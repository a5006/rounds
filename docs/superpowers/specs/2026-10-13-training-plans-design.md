# 原生训练方案库

用户已确认 Stitch 项目 ROUND Boxing Interval Timer 的方案库与新建编辑稿，并批准执行以下取舍：自定义方案新增、编辑、复制、收藏和删除；模板只允许复制后修改；本机持久化；删除保留训练记录；提示音保持准备/休息进入训练用滴、进入休息/完成用铛；方案颜色只用于方案卡片，阶段色固定；每套方案独立保存震动、音量。

模型：id、name、category、color、config、vibration、volume、favorite、template。旧的单个 config 迁移为我的训练方案。提供四套可复制预设。编辑器名字必填，参数范围保留 5 秒步长和现有边界。方案库分全部、自定义、模板、收藏四个过滤项。

保存新增/编辑后选中方案并回库，首页显示当前方案；启动前若有未完成训练，用应用内确认弹窗防止直接覆盖。运行中的配置/方案档案是独立快照，删除或修改方案不改变当前训练。刷新恢复继续使用已保存的训练快照。删除确认弹窗只删除方案，保留报告。

根据 mobile/AGENTS.md 使用 Expo Router，src/app 中只放路由；现有组件继续复用，顶部悬浮训练条和 Android 返回行为保持。将真实音量应用到 native AudioPlayer，试听也使用方案音量；全局静音仍有效。

验证：模型新增/修改/复制/模板保护/删除/收藏/恢复/迁移/参数边界/训练快照；浏览器 CRUD 与重新加载；类型检查、lint、Expo 检查、三平台导出。真机音量/震动需要设备验收。
